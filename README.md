# Навигатор — офлайн-навигатор для бездорожья

Простое приложение для телефона в машине: офлайн-карты, стрелка к точке, запись и импорт треков, лесные дороги, раскрашенные по проходимости. Курс считается по гироскопу и уточняется по GPS, поэтому на стоянке и на медленных манёврах он не скачет. Сделано по мотивам «Компас 55», только проще и под вертикальный телефон в держателе.

Один код на Flutter для **Android** и **iPhone**. Сборки выходят автоматически при каждом изменении кода.

### Android
1. Откройте ссылку на телефоне и скачайте `navigator.apk`.
2. Откройте файл. Android попросит разрешить установку из браузера или файлового менеджера, разрешите.
3. Новые версии ставятся поверх старой, точки, треки и карты сохраняются. Все сборки подписаны одним ключом.

### iPhone
IPA собирается без подписи, подписать её можно бесплатно своим Apple ID:
1. На компьютер (Windows или macOS) поставьте [Sideloadly](https://sideloadly.io) и iTunes. Для Windows нужна версия iTunes с сайта Apple, не из Microsoft Store.
2. Скачайте `navigator.ipa`, подключите iPhone кабелем, перетащите файл в Sideloadly, введите Apple ID и нажмите **Start**.
3. На iPhone откройте Настройки → Основные → VPN и управление устройством и разрешите свой Apple ID. В iOS 16 и новее ещё включите «Режим разработчика» в разделе «Конфиденциальность и безопасность».

С бесплатным Apple ID подпись действует **7 дней**. Sideloadly продлевает её сам, если включить автообновление и держать компьютер и iPhone в одной сети Wi-Fi.

## Возможности

### Карта
- **Офлайн-карты `.mbtiles`** (растровые: генштаб, спутник, топо). Добавляются из «Файлов», можно держать несколько и переключаться.
- **Онлайн-подложки**: OpenStreetMap и спутник Esri. На спутнике видно накатанные колеи, которых нет на картах.
- **Всё просмотренное сохраняется на телефоне.** Тайл, скачанный один раз, дальше берётся с диска, в том числе без связи. Совет: дома с Wi-Fi пролистайте нужный район на нужных масштабах.
- **Карта повёрнута по курсу**, ваша позиция в нижней трети экрана, чтобы впереди было видно больше дороги. Кнопка-компас переключает на режим «север вверху». Если сдвинуть карту пальцем, через 8 секунд она сама вернётся к позиции.
- Плавное движение: курс и позиция перерисовываются на каждом кадре, а между отсчётами GPS позиция достраивается по скорости.

### Курс и позиция
- **Гироскоп с поправкой по GPS.**
  - Поворот считается гироскопом вокруг вертикали, поэтому угол установки телефона в держателе не важен.
  - На скорости больше 7 км/ч GPS-курс плавно подтягивает гироскоп и убирает его дрейф.
  - На стоянке дрейф гироскопа подстраивается автоматически.
- **Магнитный компас** используется только для начального курса: в машине его сбивают кузов и электрика.
- **Счисление пути при пропадании GPS.** Если GPS молчит дольше 3 секунд, позиция продолжает двигаться по последней скорости и курсу с гироскопа. Маркер становится серым, круг погрешности растёт, сверху появляется плашка «Нет GPS · счисление».
- Внизу экрана: скорость, курс стрелкой и в градусах, источник курса (Гиро + GPS / GPS / компас / счисление) и точность GPS.

### Линейка по курсу
От стрелки вперёд идёт линия с делениями. Длина подбирается по масштабу, от 50 м до 50 км. На ней 10 делений: крупные точки через одно, мелкие между ними. Например, при длине 1 км крупные точки стоят через 200 м, мелкие через 100 м.

### Точки и цель
- Точку можно поставить долгим нажатием на карту, кнопкой «точка здесь» или вводом координат (WGS-84, градусы).
- **Цель**: карточка сверху со стрелкой, расстоянием и азимутом, на карте жёлтая пунктирная линия до точки.
- Список точек отсортирован по расстоянию, у каждой показан азимут.

### Треки
- **Запись в GPX**, в том числе с погашенным экраном: в это время висит уведомление «Идёт запись трека». Каждые 30 секунд делается автосохранение, после сбоя трек восстанавливается.
- **Импорт GPX и KML**: треки, маршруты и точки. Подходят файлы из Компас 55, OsmAnd, Wikiloc, с клубных форумов.
- Карточка трека: расстояние, общее время, время в движении, средняя и максимальная скорость, высоты и профиль высоты.
- «Поделиться» отправляет GPX-файл.

### Слои «где ездили»
- **Грунтовки по проходимости**: лесные и полевые дороги из OpenStreetMap. Загружаются для видимого места с 12-го масштаба и сохраняются на телефоне. Цвета:
  - зелёный — любая машина (grade1–2);
  - жёлтый — кроссовер (grade3);
  - красный пунктир — только джип (grade4–5, «плохое» покрытие, 4wd_only);
  - бежевый — класс дороги в OSM не указан.
- **«Здесь кто-то был»**: публичные GPS-треки, загруженные в OpenStreetMap.
- **Мои и импортированные треки** с фильтром «только на машине». Он оставляет участки, где ехали быстрее 15 км/ч, так отсеиваются пешие.

### Удобство в машине
- Тёмная тема, крупные кнопки, только вертикальная ориентация.
- Экран не гаснет, пока приложение открыто.
- Кнопка «назад» на главном экране спрашивает подтверждение. Если идёт запись, трек сохранится.
- Заставка при запуске с логотипом клуба ЧехOFF-ROAD.

## Как подготовить офлайн-карту

**SAS.Planet** (Windows):
1. Выберите карту: генштаб, спутник или другую.
2. Выделите район.
3. «Операции с выделенной областью» → «Экспорт» → формат **MBTiles**.
4. Отметьте нужные масштабы. Для леса обычно хватает 10–16, но чем больше масштабов, тем больше файл.
5. Перекиньте файл на телефон. В приложении: **Меню → Карты и треки → Добавить .mbtiles**.

Подходят любые растровые MBTiles (PNG/JPG), например из MOBAC, QGIS или gdal.

## Конфиденциальность

Приложение никуда не отправляет ваши данные: нет аккаунтов, аналитики и рекламы. Точки, треки и карты хранятся только на телефоне. В интернет приложение обращается только за тайлами онлайн-карт и за дорогами OSM для видимого места.

| Данные | Источник | Условия |

## Для разработчиков

### Сборка
Сборки делает GitHub Actions (`.github/workflows/build.yml`):
- **android** (Ubuntu): `flutter create` → `tool/patch_android.py` (разрешения, подпись, версии Gradle) → анализ кода и тесты → APK;
- **ios** (macOS M1, бесплатно для публичного репозитория): `flutter create` → `tool/patch_ios.py` (разрешения, фоновая геопозиция, iOS 15) → IPA без подписи;
- **release**: публикует `navigator.apk` и `navigator.ipa` в Releases.

Release-APK подписывается ключом `android-signing/navigator.p12`. Пароль хранится в секрете репозитория `NAV_KEYSTORE_PASSWORD`. Без секрета сборка подписывается временным ключом.

### Локально
```
flutter create --platforms=android,ios --org ru.kuxnik --project-name navigator .
rm test/widget_test.dart
python3 tool/patch_android.py
python3 tool/patch_ios.py        # на Mac
flutter pub get
dart run flutter_native_splash:create
flutter run
```

### Структура кода
```
lib/
  main.dart               запуск, заставка
  nav/geo.dart            расстояния, азимуты, форматирование
  nav/heading_filter.dart курс: гироскоп + поправка GPS + компас для старта
  state/app_state.dart    GPS, счисление пути, точки, треки, карты, настройки, запись
  data/models.dart        точки, треки, статистика, карты, настройки
  data/gpx.dart           чтение GPX/KML, запись GPX
  data/mbtiles.dart       чтение .mbtiles (SQLite)
  data/tile_cache.dart    постоянный кэш онлайн-тайлов
  data/overpass.dart      грунтовки OSM: загрузка, классификация, кэш
  ui/map_screen.dart      главный экран
  ui/map_layers.dart      слои карты
  ui/points_screen.dart   точки и редактор
  ui/library_screen.dart  карты и треки
  ui/track_screen.dart    карточка трека
  ui/layers_sheet.dart    слои
```
