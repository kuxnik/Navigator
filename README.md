# Навигатор

Простой офлайн-навигатор для машины, по мотивам «Компас 55»: карта из файла `.mbtiles`, стрелка к точке, запись и импорт треков, курс по гироскопу с поправкой по GPS.

Написан на Flutter: один код для Android и iPhone. Сейчас собирается под Android.

## Как получить APK

Последняя версия всегда лежит по одной ссылке, её можно открыть прямо на телефоне:

**https://github.com/kuxnik/Navigator/releases/latest/download/navigator.apk**

Скачайте, откройте файл и установите. Android попросит разрешить установку из этого источника. Новая версия ставится поверх старой, точки и треки сохраняются.

Все сборки перечислены на странице [Releases](https://github.com/kuxnik/Navigator/releases). Каждое изменение кода само собирается и выкладывается туда. Запустить сборку вручную: Actions → «Сборка APK» → Run workflow.

## Что умеет версия 0.1

- **Карта**
  - офлайн-карты `.mbtiles` (растровые) добавляются из «Файлов»;
  - если своих карт нет, показывается онлайн-карта OSM.
- **Курс**
  - гироскоп считает поворот вокруг вертикали, поэтому угол установки телефона в держателе не важен;
  - GPS-курс плавно поправляет гироскоп на скорости больше 7 км/ч;
  - магнитный компас нужен только для начального курса.
- **Нет GPS дольше 3 секунд — счисление пути.** Позиция двигается по последней скорости и курсу с гироскопа, маркер становится серым, круг погрешности растёт, сверху появляется плашка.
- **Карта повёрнута по курсу**, позиция в нижней трети экрана. Кнопка со стрелкой севера переключает на режим «север вверху». Если сдвинуть карту рукой, через 8 секунд она сама вернётся к позиции.
- **Линейка по курсу.** Длина подбирается по масштабу (100 м … 50 км), на ней 10 делений: крупные точки через одно, мелкие между ними.
- **Точки**
  - ставятся долгим нажатием на карту, кнопкой «точка здесь» или вводом координат;
  - из списка можно выбрать цель: появится карточка со стрелкой, расстоянием и азимутом и жёлтая линия до цели.
- **Запись трека в GPX**, в том числе в фоне: при записи висит уведомление. Каждые 30 секунд делается автосохранение, после сбоя трек восстанавливается.
- **Импорт GPX и KML**: треки и точки, включая GPX из Компас 55. Для каждого трека есть карточка со статистикой и профилем высоты, и его можно отправить через «Поделиться».
- **Слои**
  - «Здесь кто-то был» — публичные треки OSM, онлайн;
  - «Мои и импортированные» — с фильтром «только на машине, быстрее 15 км/ч»;
  - линейка.
- Экран не гаснет. Кнопка «назад» на главном экране спрашивает подтверждение выхода.

## Как сделать карту .mbtiles

В SAS.Planet выделите район и выберите «Операции с выделенной областью» → «Экспорт» → формат **MBTiles**, укажите нужные масштабы. Готовый файл перекиньте на телефон и в приложении нажмите «Меню» → «Карты и треки» → «Добавить .mbtiles».

## Пока нет (следующие шаги)

- Слой «Грунтовки по проходимости» из OSM: для него нужно заранее подготовить векторные данные по области.
- Ведение по треку.
- Скорость с CAN-шины через ESP32 по Bluetooth для точного счисления пути.
- Форматы `.sqlitedb` и `.rmap`.
- Сборка под iPhone (нужен Mac).
